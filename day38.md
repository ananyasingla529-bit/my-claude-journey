# ⌨️ Typing Speed Studio

A premium typing learning platform built as a single-file HTML application using HTML, CSS, and JavaScript.

Originally inspired by a typing speed challenge, this project was expanded into a complete learning platform with gamification, programming practice, analytics, and adaptive learning.

---

## Features

### 🎯 Typing Modes
- Time Mode
- Word Count Mode
- Quote Mode
- Programming Mode
- Custom Text Mode
- Adaptive Mode
- Focus Mode
- Zen Mode

### 💻 Programming Practice
- HTML
- CSS
- JavaScript
- Python
- Java
- SQL
- C++
- JSON
- Git Commands
- Linux Commands

### 📊 Analytics Dashboard
- Words Per Minute (WPM)
- Raw WPM
- Accuracy
- CPM
- Mistake Count
- Completion Percentage
- Consistency Score
- Session History
- Personal Best Records

### 🎮 Gamification
- XP System
- Level Progression
- Achievement Badges
- Daily Challenges
- Progress Tracking

### 📈 Smart Learning
- Adaptive Difficulty
- Personalized Feedback
- Error Analysis
- Improvement Suggestions

### 🎨 UI Features
- Responsive Design
- Dark & Light Themes
- Theme Customization
- Keyboard Shortcuts
- Smooth Animations

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

---

## What I Learned

This project helped me understand how small improvements can transform a simple application into a richer learning experience by combining education, gamification, and interactive design.
