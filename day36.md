# Day 36 - Cognitive Pattern Explorer

## Project
Cognitive Pattern Explorer

## Description
Built a fully offline interactive psychology-inspired learning application using HTML, CSS, and Vanilla JavaScript.

The application explores different thinking tendencies through interactive scenarios while encouraging self-reflection instead of assessment.

## Features

- Single HTML file
- Works completely offline
- Responsive design
- Calm & Stress Mode
- Interactive Chapters
- Native Drag & Drop
- Touch Support
- Progress Tracking
- Personalized Reflection Journal
- Thinking Style Breakdown
- Keyboard Accessibility
- Reduced Motion Support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Learning

Today I learned:

- Building educational experiences
- Native Drag & Drop
- Creating reusable JS components
- State management without frameworks
- Personalized feedback generation
- Accessible UI design
