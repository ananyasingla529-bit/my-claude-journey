# Day 20 – Face Puzzle Game using HTML, CSS & JavaScript 🎮📸

## Objective

Built a complete browser-based Face Puzzle Game that captures a user's photo using the webcam and converts it into an interactive sliding puzzle.

- Browser APIs make it possible to build interactive applications without external software.
- Combining Canvas with JavaScript enables dynamic image processing.
- LocalStorage is useful for maintaining user progress and leaderboards.
- Careful prompt engineering helps generate complete, production-ready applications.
