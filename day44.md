# Day 44 – LinkedIn Profile Roast & Rebuild Assistant

## Overview

For Day 44 of the ABTalks AI Challenge, I built a **LinkedIn Profile Roast & Rebuild Assistant** using Claude AI.

The application analyzes a user's LinkedIn profile and provides structured feedback along with recommendations to improve their professional profile.

## Features

* Collects LinkedIn profile information
* Reviews profile sections
* Provides profile analysis
* Suggests improvements
* Rewrites important profile sections
* Recommends relevant skills
* Generates a personalized action plan

## What I Learned

* Structuring AI-driven user interactions
* Designing career-focused AI applications
* Creating organized prompts for profile analysis
* Improving prompt engineering skills

## Tech Stack

* HTML
* CSS
* JavaScript
* Claude AI
