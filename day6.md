# Day 6 - ATS Resume Optimization

## Objective
Learn how ATS systems evaluate resumes and how AI can optimize a resume for better recruiter visibility.

## ATS Analysis

### Previous Score
62/100

### Optimized Score
85/100

### Changes Made
- Improved professional summary with relevant keywords
- Reorganized technical skills into categories
- Expanded project descriptions using stronger action verbs
- Standardized resume section headings
- Removed redundant information
- Improved overall ATS readability

## Key Learning

Today I learned that ATS systems scan resumes before recruiters read them. A resume should not only look good but also be easy for software to parse.

## Biggest Insight

Small improvements such as using standard headings, stronger action verbs, and relevant keywords can significantly improve ATS performance.

## Future Improvements Suggested

- Add CGPA if above 3.5
- Include relevant coursework
- Earn certifications
- Add measurable project outcomes
- Add GitHub portfolio link
- Build more projects
