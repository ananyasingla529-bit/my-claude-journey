# Day 33 – Media Integrity Analyzer

## Overview

Media Integrity Analyzer is a single-file HTML application created as part of the AB Talks 60 Days AI Challenge.

The application teaches media literacy through interactive learning instead of traditional quizzes. Users learn how headlines, emotional language, and persuasive techniques influence the way information is consumed online.

---

## Features

- Headline Detective
- Emotion Detector
- Live Media Integrity Metrics
- Media Integrity Dashboard
- Replay with Randomized Scenarios
- Multiple Color Themes
- Responsive Design
- Premium Dark UI
- Offline Support
- Single HTML File

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

---

## Learning Outcomes

This project helped me understand:

- Media literacy concepts
- Emotional manipulation in digital content
- Headline accuracy evaluation
- Interactive educational UI design
- JavaScript DOM manipulation
- State management without frameworks
