# Day 3 - Role-Based Prompting

## Question Used

How can a college student improve coding skills and become internship-ready?

## Prompt 1 - Without Role

The response was general and covered coding practice, projects, interviews, and internships.

## Prompt 2 - Founder Role

The response focused on:

* Building useful projects
* Showing initiative
* Creating a portfolio
* Demonstrating problem-solving ability

## Prompt 3 - Developer Role

The response focused on:

* Data Structures and Algorithms
* Coding practice
* Git and GitHub
* Debugging and software development skills

## Key Learnings

* Assigning a role changes the AI's perspective.
* Different roles provide different advice for the same question.
* Role-Based Prompting helps generate more targeted and relevant responses.
* Giving AI context improves output quality.

## Reflection

Today I learned that AI responds differently based on the role assigned to it. A founder focuses on business value and initiative, while a developer focuses on technical skills and coding. This showed me how Role-Based Prompting can be used to get more useful answers depending on the situation.
