# Day 48 – Compare & Decide Builder

## 🚀 Overview

Built **Compare & Decide Builder**, an interactive decision-making application that compares multiple options using real-world research and customizable evaluation criteria.

## ✨ Features

* Interactive comparison dashboard
* Adjustable criteria weighting
* Live ranking updates
* Real-world source citations
* Transparent research panel
* Responsive single-page interface
* Professional data visualization
* Comprehensive comparison reports

## 📚 What I Learned

* Designing data-driven decision support systems
* Building interactive comparison dashboards
* Presenting transparent research with citations
* Improving UX for analytical applications
* Creating trustworthy AI-assisted tools

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript
