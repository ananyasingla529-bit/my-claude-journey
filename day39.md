# 📄 Day 39 – PDF Toolkit

Today's challenge was to build a PDF Splitter & Merger.

Instead of creating only those two tools, I expanded the project into a complete Offline PDF Toolkit that provides a more polished and practical user experience.

## 🚀 Features

### 📖 PDF Reader
- Page navigation
- Jump to page
- Zoom controls
- Fit page / Fit width
- Reading progress
- Thumbnail sidebar
- Dark & Light reading modes

### ✂️ PDF Splitter
- Split by page range
- Split every N pages
- Odd/Even pages
- Equal page splits
- Multiple custom ranges
- Output preview

### 📚 PDF Merger
- Merge multiple PDFs
- Merge selected page ranges
- Drag-and-drop file ordering
- Live merge preview
- Output summary

### ✨ Additional Enhancements
- Premium glassmorphism interface
- Responsive desktop & mobile design
- Internal application navigation
- Recent files section
- Local usage statistics
- Processing animations
- Keyboard shortcuts
- Dark & Light themes
- Offline-first architecture

## 🛠️ Tech Stack

- HTML
- CSS
- Vanilla JavaScript

This project focuses on creating a complete productivity application while keeping everything inside a single standalone HTML file.
