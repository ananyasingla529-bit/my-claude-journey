# Day 4 - Chain-of-Thought Prompting

## What I Did Today

Today I learned about Chain-of-Thought Prompting.

I used a career roadmap prompt that first asked me about:
1. My current situation
2. My existing skills
3. My goal
4. My timeline

After collecting my answers, Claude analyzed my situation and created a personalized roadmap.

## My Inputs

### Current Situation
Student (2nd Year BTech CSE)

### Current Skills
- Java (Beginner)
- Python Programming (Beginner)

### Target Goal
Land a software development internship and improve coding skills.

### Timeline
1 Year

## Key Learnings

- AI gives better results when it gathers information before answering.
- Breaking a problem into steps improves the quality of the output.
- A clear roadmap makes goals easier to achieve.
- Projects, coding practice, and networking are all important for internships.

## Biggest Insight

The most surprising insight was that building projects and maintaining a GitHub portfolio can be just as important as learning programming concepts.

## Reflection

Today I learned that Chain-of-Thought Prompting helps AI think through a problem step by step before generating a solution. This produced a much more personalized and useful roadmap than a simple question would.
