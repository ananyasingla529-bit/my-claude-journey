# Day 27 – Interactive Healthcare Journey Story

## 🚀 Challenge

Built an interactive healthcare journey simulator that explains the Prior Authorization process through a story-driven experience.

## ✨ Features

- Interactive healthcare story
- Follow Rahul's medical journey
- Guided explanations by Priya
- Choice-based branching decisions
- Progress tracker
- Multiple story chapters
- Educational healthcare workflow
- Responsive UI
- Restart and replay support
- Modern HTML, CSS & JavaScript implementation

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 📚 What I Learned

- Designing interactive educational experiences
- Building branching story flows
- Managing application state
- Creating responsive user interfaces
- Improving user engagement with storytelling
