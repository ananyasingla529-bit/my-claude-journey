# 🎉 CareerIQ v1.0.0 Officially Released!

After completing the AB Talks 60-Day Claude AI Challenge and an intensive 10-day capstone sprint, I'm excited to officially launch **CareerIQ v1.0.0**.

🔗 Live Demo
https://ananyasingla529-bit.github.io/CareerIQ/

🔗 GitHub Repository
https://github.com/ananyasingla529-bit/CareerIQ

---

## 🚀 Features

- AI-powered Resume vs Job Description analysis
- Overall Fit Score
- Category-wise breakdown
- AI reasoning with evidence
- Strengths & skill gap analysis
- Eligibility detection
- Apply Confidence Meter
- Recommended Next Action
- Resume Rewrite Assistant
- Save analyses dashboard
- Compare multiple job analyses
- Offline fallback engine
- Responsive design
- Accessibility improvements
- Dual light & dark themes
- Production-ready documentation
