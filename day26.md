# Day 26 – Prior Authorization Workflow Simulator

## Overview

Today I built an interactive Prior Authorization Workflow Simulator using HTML, CSS and Vanilla JavaScript.

The simulator demonstrates the healthcare prior authorization process through an educational drag-and-drop interface.

## Features

- Patient, Provider and Payer workflow lanes
- Drag-and-drop workflow
- Multiple patient scenarios
- Medical necessity evaluation
- Prior Authorization document collection
- Submission to payer
- Approval, Pend, Denial, Appeal and Peer-to-Peer Review
- Educational explanations
- Progress tracker
- Days elapsed counter
- Efficiency score
- Workflow completion summary
- Celebration animation
- Restart / New Patient functionality
- Responsive design

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
