# Day 16 - Claude Custom Skills

## Objective
Created a reusable Claude Custom Skill for stock fundamental analysis.

## Skill Name
stock-fundamental-research

## What I Built
A custom Claude skill that analyzes Indian and global stocks using:
- Financial statements
- Valuation metrics
- Growth analysis
- Ownership patterns
- Risk factors
- Peer comparison

## Test Performed
Generated a stock analysis report for TCS.

## Key Learnings
- Custom Skills eliminate prompt repetition.
- Claude can reuse instructions across multiple conversations.
- Well-structured prompts improve consistency and output quality.
- Financial analysis can be standardized using reusable workflows.
