# Day 37 - Task Compass

## Project
Task Compass – Learn How Work Flows Through Real Organizations

## Description

Built an interactive management simulation that teaches ownership, delegation, collaboration, and workflow thinking using HTML, CSS, and Vanilla JavaScript.

### Enhancement

The original challenge expected the workplace type to be selected before generating the application.

Instead, I extended the concept by creating a Multiple Workplace Simulator where users can select different workplace environments directly inside the application. This makes the project replayable and allows users to compare how workflows differ across industries.

## Features

- Offline Single HTML File
- Multiple Workplace Selection
- Drag-and-Drop Gameplay
- Ownership Simulation
- Task Routing
- Collaboration Challenges
- Organizational Thinking Dashboard
- Reflection Report
- Responsive UI
- Glassmorphism Design

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Key Learnings

- Organizational workflow modeling
- Interactive drag-and-drop
- Reusable JavaScript components
- Educational UI design
- State management
