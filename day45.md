# Day 45 – AI Decision Strategist

## Challenge
Built an interactive **AI Decision Strategist** as part of the **ABTalks 60 Days AI Challenge**.

## Project Overview

This application helps users think through difficult decisions instead of simply providing answers. It collects information through a guided interview and generates a complete decision report.

## Features

- Guided 4-question decision interview
- Decision summary
- Option comparison cards
- Assumption & cognitive bias analysis
- Interactive decision matrix
- Premortem analysis
- 7-day action plan
- Final AI verdict
- Shareable summary cards
- Responsive single-page HTML application
- Dark modern UI with animations

## What I Learned

- Structuring AI prompts for guided conversations
- Designing decision-support systems
- Building interactive HTML dashboards
- Presenting complex information in a clean UI
- Using AI to improve critical thinking rather than simply providing answers

## Tech Stack

- HTML
- CSS
- JavaScript
- Claude AI
