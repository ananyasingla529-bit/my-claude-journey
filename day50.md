# 🚀 Day 50 – Defend Your Experience

## 📖 Overview

Built **Defend Your Experience**, an AI-powered interview preparation application that helps users confidently defend every professional or academic claim they make.

Unlike traditional resume reviewers, this application acts as an adaptive interviewer. It extracts meaningful claims from uploaded documents and continuously asks personalized follow-up questions to test depth, clarity, and confidence.

## ✨ Features

- Adaptive AI interview simulation
- Support for resumes, LinkedIn profiles, portfolios, GitHub profiles, project reports, research papers, startup pitches, SOPs, and more
- Personalized follow-up questions
- Confidence indicators & progress tracking
- Defense Report highlighting strengths and weak areas
- Session history with local storage
- Responsive modern UI

## 📚 What I Learned

- Designing adaptive AI interview systems
- Building personalized learning experiences
- Improving UX for interview preparation
- Structuring AI-driven feedback loops
- Creating practical AI applications that build confidence
