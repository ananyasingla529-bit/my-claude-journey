# Day 42 - Personal Financial Command Center

## 🚀 Project Overview

For Day 42 of the AB Talks Claude AI Challenge, I built a **Personal Financial Command Center**, a premium single-page HTML application that helps users understand and improve their financial health.

Rather than creating a dashboard for only one user profile, I redesigned the concept into an **adaptive financial platform** that personalizes itself based on the user's needs.

---

## ✨ Key Enhancements

- Adaptive onboarding for different user profiles
  - Student
  - Salaried Employee
  - Freelancer
  - Business Owner
  - Investor
  - Family
  - Retired
  - Custom Profile

- Personalized dashboard generation

- Financial Health Score

- AI Financial Coach

- Smart Budget Planner

- Savings Goal Planner

- Loan & EMI Planner

- SIP & Compound Interest Calculators

- Retirement Planner

- Subscription Tracker

- Net Worth Tracker

- Cash Flow Analytics

- What-If Financial Simulator

- Interactive Charts & Reports

- Financial Learning Center with quizzes and flashcards

- XP System, Achievement Badges & Progress Tracking

- Local Storage support

- Responsive UI for Desktop, Tablet & Mobile

- Dark Mode & Modern Glassmorphism Design

---

## 📚 What I Learned

- Designing adaptive user experiences
- Creating personalized dashboards
- Structuring complex financial data into intuitive UI
- Improving user engagement through gamification
- Thinking beyond the original requirements by focusing on real-world usability

---

## 🛠 Tech Stack

- HTML
- CSS
- Vanilla JavaScript
