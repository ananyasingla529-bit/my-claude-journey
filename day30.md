# Day 30 – Supply Chain Builder

## Project Overview

Today I built **Supply Chain Builder**, an interactive educational simulator that teaches beginners the fundamentals of supply chain management through real-world decision making.

The application explains every concept before asking the user to make decisions, making complex business topics simple and interactive.

## Features

- Random company generation
- Supplier strategy selection
- Factory location planning
- Warehouse strategy
- Transportation method selection
- Inventory strategy
- Live business metrics
- Overall Supply Chain Score
- Personalized recommendations
- Replay functionality
- Responsive UI

## Technologies Used

- React (CDN)
- HTML
- CSS
- Vanilla JavaScript

## Learning Outcomes

- Supply chain fundamentals
- Business trade-offs
- Interactive UI design
- React useState
- Dynamic state management
