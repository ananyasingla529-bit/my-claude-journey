# Day 5 - Context Engineering

## What I Did Today

Today I learned about Context Engineering.

I compared two prompts:

### Prompt A
A general prompt asking for a 30-day learning roadmap without any personal information.

### Prompt B
The same prompt but with details about my current situation, skills, goals, experience level, available time, and learning preferences.

---

## My Context

- Current Situation: 2nd Year CSE Student
- Current Skills: Java (Beginner), Python Programming (Beginner), Problem Solving, Basic GitHub
- Goal: Land a software development internship and improve coding skills
- Available Time: 2 Hours per Day
- Experience Level: Beginner
- Preferred Learning Style: Projects and Videos

## Key Learnings

- Context improves AI responses significantly.
- More information leads to more relevant outputs.
- Personalized roadmaps are easier to follow.
- AI performs better when it understands the user's situation.

---

## Answers to Reflection Questions

### 1. Which roadmap feels more personalized?
Prompt B.

### 2. Which roadmap would you actually follow?
Prompt B because it matches my goals and current skill level.

### 3. What role did context play?
Context helped Claude understand my background and create a roadmap tailored to my needs instead of giving generic advice.

---

## Reflection

Today I learned that adding context is one of the most effective ways to improve AI outputs. The same prompt produced much better results when I included information about my skills, goals, and experience level.
