# 🤖 Day 40 – AI Interview Coach

## Overview

For Day 40 of the ABTalks AI Challenge, I built an **AI Interview Coach** using HTML, CSS, and JavaScript.

The application is designed to simulate an AI-powered interview preparation experience by providing personalized guidance and structured feedback through a clean, responsive interface.

## Features

- 🤖 AI Interview Coach
- 📄 Resume Input Support
- 💬 Interactive Chat Interface
- 📊 Personalized Feedback
- 📝 Structured Recommendations
- 📱 Responsive Design
- ⚡ Smooth Animations
- 📚 Documentation Panel
- 🌐 Single-File HTML Application

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Prompt Engineering

## Key Learnings

- Designing AI assistant workflows
- Writing better system prompts
- Building user-friendly interfaces
- Improving frontend development skills
- Understanding conversation design
