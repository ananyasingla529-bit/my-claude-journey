# 🕵️ Day 34 – Marketing Detective

## 📖 Overview

Marketing Detective is a single-file interactive web application built as part of the **AB Talks 60 Days AI Challenge**.

Instead of simply teaching marketing concepts, the application lets users investigate fictional marketing campaigns, analyze evidence, identify mistakes, and discover practical solutions through a detective-style experience.

---

## ✨ Features

- 🕵️ Detective-themed UI
- 📁 Randomized Marketing Case Studies
- 📊 Campaign Metrics Analysis
- 📝 Customer Feedback Investigation
- 🎯 Marketing Mistake Identification
- 🧩 Drag-and-Drop Evidence Board
- 📚 Interactive Learning Report
- 🎨 Multiple Color Themes
- 📱 Responsive Design
- 💻 Offline Single HTML File

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React (CDN + Babel) / Vanilla JavaScript (offline-compatible implementation)

---

## 📚 Learning Outcomes

Through this project I explored:

- Marketing campaign analysis
- Data-driven decision making
- Customer behavior interpretation
- UI/UX design for educational applications
- Interactive frontend development
- Prompt engineering
