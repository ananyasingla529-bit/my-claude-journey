# Day 31 – AI Supply Chain Control Tower

## Project Overview

Today I built **AI Supply Chain Control Tower**, an interactive simulation that allows users to experience the role of a Head of Operations managing a global supply chain.

The application presents real-time operational alerts where each decision directly impacts important business KPIs.

## Features

- Real-time operational alerts
- Priority-based incident management
- Live KPI dashboard
- Countdown timer
- Dynamic scoring system
- Delayed decision consequences
- Event log
- Performance summary
- Pause and Help functionality
- Responsive enterprise-style dashboard

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript

## Learning Outcomes

- Supply chain operations
- Incident prioritization
- KPI monitoring
- Interactive UI development
- Modular JavaScript programming
