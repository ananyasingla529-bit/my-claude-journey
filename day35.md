# 🧩 Day 35 – Prompt Puzzle: Master AI Prompting Through Play

## 📖 Overview

Prompt Puzzle is a single-file interactive web application developed as part of the **AB Talks 60 Days AI Challenge**.

The application teaches prompt engineering through engaging puzzle-based activities, allowing users to improve their prompting skills by building, optimizing, and evaluating AI prompts.

---

## ✨ Features

- 🧩 Build the Prompt Challenge
- 🧹 Clean the Prompt Challenge
- 🎯 Choose the Best Prompt
- 📊 Live Performance Scoring
- 📈 Prompt Performance Dashboard
- 🧬 Prompt DNA Visualization
- 🔄 Replay with Randomized Scenarios
- 💻 Offline Single HTML File
- 📱 Responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React (CDN) / Vanilla JavaScript (offline-compatible implementation)

---

## 📚 Learning Outcomes

This project helped me understand:

- Prompt engineering principles
- Writing structured AI instructions
- Optimizing prompts for better outputs
- Educational UI/UX design
- Interactive frontend development
- Building gamified learning experiences
