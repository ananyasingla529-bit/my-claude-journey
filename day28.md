# Day 28 – Hospital Admission Readiness Simulator

## 🚀 Challenge

Built a Hospital Admission Readiness Simulator that helps users understand the healthcare admission workflow through an interactive simulation. The application evaluates admission readiness based on documentation, insurance, prior authorization, physician orders, consent, and bed availability while providing educational insights throughout the process.

## ✨ Features

- Provider & physician information setup
- Multiple diagnosis scenarios
- Admission type selection
- Prior Authorization workflow
- Admission Readiness Score
- Timeline-based admission process
- Risk Tracking Dashboard
- Care Coordination Cards
- Governance Snapshot
- Final Admission Decision
- Responsive healthcare-themed UI

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript

## 📚 What I Learned

- Healthcare admission workflow
- Prior Authorization lifecycle
- Clinical documentation importance
- Risk-based scoring systems
- Interactive workflow design
- Responsive UI development
